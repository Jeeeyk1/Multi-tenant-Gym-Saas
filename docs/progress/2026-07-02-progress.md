## Cost controls + write actions (same session, after live test)

### Cost controls
- **Quota reset bug fixed** — `getEntitlement` now derives period usage by summing `ai_usage_log`
  since `subscription.currentPeriodStart` instead of the ever-incrementing `aiTokensUsed` counter,
  so the quota resets automatically each billing period (no reset job, self-healing). `recordUsage`
  now only writes the log. Quota is the org's unified AI budget (`aiTokenQuotaMonthly`, all feature keys).
- **Per-user rate limit added** — `RateLimiterService` (Redis fixed-window, 15 req / 60s per
  `caller.sub`), checked before any DB/model call → `429 RATE_LIMITED`.
- Recommended to the user (their action): set an Anthropic Console spend cap (the real backstop),
  rotate the key before production, move to a secrets manager.

### Write actions (assistant can now take actions, not just read)
Decisions: **confirm-first** (system-prompt enforced), scope = **member invite + a few lifecycle actions**.
- New action tools wrap the existing authoritative use cases (all validation + per-action permission
  checks reused, nothing bypassed): `register_member` (members.create, sends invite email),
  `renew_membership` (members.renew), `suspend_member` (members.suspend), `reactivate_member`
  (members.edit). Plus `list_membership_plans` read tool (reuses `MembershipPlansRepository`).
- `ToolRegistry.execute(call, ctx)` now threads `ToolContext { gymId, caller }` — write tools pass
  `caller` to the use case so the action re-checks the caller's specific permission. A user with only
  `insights.query` can chat but any write throws `PERMISSION_DENIED` (surfaced as a tool error).
- Module wiring: `MembersModule`/`RenewalsModule` now export the reused use cases; `AiInsightsModule`
  imports Members/Renewals/MembershipPlans.
- Confirm-first: system prompt mandates summarize → get explicit "yes" → only then call the action
  tool; never act on the turn it first proposes. (Prompt-level guardrail; a hard client-side
  tool-confirmation protocol is the stronger future option.)
