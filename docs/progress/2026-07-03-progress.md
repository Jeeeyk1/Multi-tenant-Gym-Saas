# Progress — 2026-07-03

## 1. Duplicate `plans` rows — fixed

**Root cause:** `plans` had no unique constraint, so `004_plans`' `ON CONFLICT DO NOTHING`
never fired and every `db:seed` re-inserted the three tiers (12 copies of each accumulated).

**Fix — migration `db/migrations/0037_dedupe_plans.sql`:**
- Repoints any subscription on a duplicate to the canonical (earliest, `DISTINCT ON (name)`)
  plan — before the delete, because `subscriptions.plan_id` is `ON DELETE RESTRICT`.
- Deletes duplicate plans (their `plan_features` cascade-delete via FK).
- Adds `UNIQUE (plans.name)` (guarded by a `pg_constraint` check so it's re-runnable).
- Prisma `Plan.name` marked `@unique`.

**Verified:** 1 row per tier; constraint present; both subscriptions repointed to a valid Growth
plan with `ai_assistant`; re-ran `db:seed` twice more — still 1 per tier (idempotent now).

## 3. Mobile ↔ web staff parity — 4 features added to mobile

The staff mobile app was missing Plans, Renewals, Chat, Badges, Staff-mgmt, Settings vs web.
Per the user's picks, added the four with real mobile value; Staff-management + Settings left
web-only (config tasks). Also refactored More → Tools into a permission-gated, data-driven nav
list (gating mirrors the web sidebar) and registered all four as hidden routes in `(staff)/_layout.tsx`.

- **Renewals** (`(staff)/renewals.tsx`) — gym-wide renewals history (read-only). The renew
  *action* already existed on the member-detail screen; this adds the list web has.
  New: `staffService.listGymRenewals`, `useGymRenewals`, `GymRenewal` type. Gated `members.renew`.
- **Plans** (`(staff)/plans.tsx`) — read-only list of membership plans (name, type, price,
  duration, active). New: `staffService.listPlans`, `useGymPlans`; extended `MembershipPlan`
  with optional `description`/`isActive`. Gated `plans.view`.
- **Badges** (`(staff)/badges.tsx`) — award flow: custom-badge catalog → tap a badge → search/
  select member → optional note → award (reuses `POST /badges/award`). New `badges.service.ts`,
  `hooks/badges.ts` (`useCustomBadges`, `useAwardBadge`), `CustomBadge` type. Gated `badges.award`.
- **Chat moderation** (`(staff)/chat.tsx`) — socket.io community chat (same protocol as the
  member screen): view, send, and long-press → confirm → delete (moderation, via
  `chatService.deleteMessage` REST; server broadcasts `message.deleted`). Gated `chat.manage`.

**Verified:** `tsc --noEmit -p apps/mobile/tsconfig.json` — 0 errors. Lint clean on the new files
