# Progress — 2026-07-31

## Staff / owner mobile app — UI/UX redesign (increment 1) — DONE

Reworked the visual hierarchy of the staff/owner section of the Expo app. Direction was
approved via an HTML preview artifact (Dashboard before/after + Members) before touching code.
Constraint from the owner: **the accent must stay driven by the tenant `theme.primary`** — every
accent surface computes from it at runtime (`theme.primary + 'XX'` alpha, the existing codebase
convention), only semantic status colors (expiring amber, expired red) are fixed. No light-mode
migration in this pass — neutrals stay on the dark palette.

### What changed
- **New `components/StaffHeader.tsx`** — one safe-area-aware header for every staff screen.
  Replaces the hardcoded `Platform.OS === 'ios' ? 48/52 : 24` top padding that was wrong on
  notched Androids and non-48pt iPhones. Props: `title`, `greeting`, `subtitle`, `right`,
  `onBack`, `borderBottom`. Greeting accent follows `theme.primary`.
- **`app/_layout.tsx`** — wrapped the tree in `SafeAreaProvider` (the lib was already a dep but
  had no provider, so `useSafeAreaInsets()` would have returned 0). Applied to both the splash
  branch and the main app.
- **Dashboard (`(staff)/dashboard.tsx`)** — biggest change. Replaced the single gradient stat +
  two gray action rows with:
  - a **2×2 pulse grid** (Active right now / Total members / Expiring soon / Expired), each a
    tinted icon chip + tabular value; the live tile is themed, the two retention tiles carry
    semantic amber/red. Every tile is tappable and deep-links into the relevant view.
  - a **prominent themed CTA button** ("Check in a member") that no longer looks like a passive
    list row.
  - pending PR reviews surfaced as an **amber alert**, not another gray row.
  - Header is now fixed (sticky) above the scroll instead of scrolling with content.
  - Metrics are real: `activeCheckIns.length`, `members.meta.total`, and client-derived
    expiring(≤7d, active)/expired counts. Safe because the Standard plan caps the roster at 150,
    under the 200-member fetch limit. "Renewals due" was dropped — that endpoint is a *history*
    log, not a forward-looking due list.
- **Members (`(staff)/members.tsx`)** — added **filter chips** (All / Active / Expiring / Expired)
  with live counts, colored to status; the dashboard tiles pass a `filter` route param that
  preselects the chip (synced via effect since expo-router keeps tabs mounted). Status badges are
  now filled tints instead of thin outlines.
- **Consistency pass** — migrated Check-ins, More, Renewals, and Announcements headers to the
  shared `StaffHeader` (removes their duplicated hardcoded-padding headers), and tinted the
  avatar bubbles on Dashboard/Members with `theme.primary`.

### Verification
- `tsc --noEmit` clean.
- `pnpm --filter @gym-saas/mobile lint` — 0 errors, 15 warnings, all pre-existing
  (`react-hooks/exhaustive-deps` on the `members`/`announcements` `?? []`-into-useMemo pattern
