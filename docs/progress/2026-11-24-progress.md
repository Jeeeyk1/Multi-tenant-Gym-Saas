## Phase 4A — CI safety net — DONE (PR #5)

### What changed
- **Typecheck and lint for all five apps.** Admin, landing and mobile were never checked before.
  - Admin and landing got the same Next ESLint setup as web.
  - Two landing lint errors fixed (unescaped apostrophes).
- **Shared packages** (`packages/*`) are built before typecheck. A fresh checkout has no `dist/`, so admin couldn't
  resolve `@gym-saas/contracts`.
- **New "Migrations & schema drift" job.** It applies all migrations to an empty Postgres 16, then
  `db/scripts/check-schema-drift.ts` (`pnpm db:check-drift`) compares tables, columns and nullability with
  `schema.prisma`. Documented in `docs/03-engineering/migration-workflow.md`.
- **New "Security" job:**
  - gitleaks secret scan (blocking): no leaks found;
  - `pnpm audit --prod` (report-only): **261 advisories, 7 critical, 133 high** to triage in Phase 4E.
- **Node 22** pinned in `.nvmrc` (matches the deploy guide); CI reads it. Superseded runs are cancelled.

### Decisions
- **The drift check only compares structure.** Prisma's own `migrate diff` reports about 430 lines of harmless
  differences (index and FK names, VARCHAR vs TEXT) that a strict check would always fail on.
- **The audit doesn't block yet.** It would fail every PR today; make it blocking after the 4E triage.

### Verification
- Locally:
  - drift check passes on a fresh database (47 migrations, 55 tables);
  - it fails on an injected extra column and on a nullability change.
- CI on PR #5: all five jobs green (Type Check, Lint, Tests, Migrations & schema drift, Security).

## Meal logging UX redesign — DONE

- **Nutrition screen:** the inline forms were replaced by a "Log a meal" button and a "Meal idea" button, each
  opening a bottom sheet. A toast with the calories left appears after logging (also announced to VoiceOver).
- **Log a meal sheet** (`components/nutrition/AddMealSheet.tsx`):
  - three ways in: Snap it (camera/gallery → photo analysis, moved here from AI Coach), Describe it (with
    tap-to-add examples), Quick add (numbers);
  - "Eat it again" chips re-log recent meals with no AI call;
  - remaining monthly uses shown on each AI option.
- **Thinking state** (`AiThinking`): the coach hops while status lines cycle, over a shimmering result skeleton.
- **Result card** (`MealEstimateCard`):
  - large calories and macro pills;
  - a portion control (½× to 2×) that rescales locally with no extra AI call, and the portion is written into
    the logged description;
  - an "after this you'll have N kcal left" line.
- **Meal idea sheet** (`MealIdeaSheet`): confirm first (what's left today, optional style chips Quick / Budget /
  High protein / Light, "uses 1 of N"), then the thinking state, then the dish with its ingredients, the portion
  control and "I ate this".
- **API:** optional `style` (`MealStyle` enum) on `ai/meal-suggestion`, added to the prompt.
- **Review fixes:**
  - a render loop on the meal-idea result;
  - Android back can't dismiss a sheet mid-request, which used to leave stale screens;
  - unknown macros stay unknown instead of being saved as 0;
  - AI buttons are disabled at 0 uses left;
  - a toast race.
