## Phase 4A — CI safety net — DONE (PR #5)

### What changed
- **Typecheck and lint for all five apps.** Admin, landing and mobile were never checked before.
  - Admin and landing got the same Next ESLint setup as web.
  - Two landing lint errors fixed (unescaped apostrophes).
- **Shared packages** (`packages/*`) are built before typecheck. A fresh checkout has no `dist/`, so admin couldn't
  resolve `@gym-saas/contracts`.
- **New "Migrations & schema drift" job.** It applies all migrations to an empty Postgres 16, then
  `db/scripts/check-schema-drift.ts` (`pnpm db:check-drift`) compares tables, columns and nullability with
  `schema.prisma`. Documented in `docs/03-engineering/migration-workflow.md`.
- **New "Security" job:**
  - gitleaks secret scan (blocking): no leaks found;
  - `pnpm audit --prod` (report-only): **261 advisories, 7 critical, 133 high** to triage in Phase 4E.
- **Node 22** pinned in `.nvmrc` (matches the deploy guide); CI reads it. Superseded runs are cancelled.

### Decisions
- **The drift check only compares structure.** Prisma's own `migrate diff` reports about 430 lines of harmless
  differences (index and FK names, VARCHAR vs TEXT) that a strict check would always fail on.
- **The audit doesn't block yet.** It would fail every PR today; make it blocking after the 4E triage.

### Verification
- Locally:
  - drift check passes on a fresh database (47 migrations, 55 tables);
  - it fails on an injected extra column and on a nullability change.
- CI on PR #5: all five jobs green (Type Check, Lint, Tests, Migrations & schema drift, Security).
