## Decisions made

### Web/admin modals use the shared `Dialog`
- `packages/ui` `Dialog` gained a labelled close button (last in DOM so first focus lands on content), focus
  return to the opener (also when the parent unmounts it), a reset of the closing state on every open, and a
  native `close` handler that ignores our own late close events (safe under React Strict Mode).
- Backdrop closes only when the press starts and ends outside the dialog box.

### Mobile gym colour as text
- `readableAccent()` (`apps/mobile/src/theme/accent.ts`) shifts the gym colour's lightness until it reaches
  4.5:1 on the page and card backgrounds, keeping the hue; exposed as `theme.accentText` and used for text and
  the dock's active icon/label. Fills and backgrounds keep `theme.primary`.
- Light palette: `textMuted` #6C6C7E (4.61:1), `warning` #AD5008, `success` #147A3A.
